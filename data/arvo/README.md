`arvo.db` is the official SQLite metadata database. It records project and
repository metadata, vulnerable/fixed reproducer commands, located patches,
sanitizer crash information, and verification status. The vulnerable and fixed
source trees are supplied separately through per-case Docker images and are not
stored in this directory.
